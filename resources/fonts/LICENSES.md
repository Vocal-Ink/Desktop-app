# Bundled fonts

All fonts here are licensed under the SIL Open Font License 1.1 (see the OFL
texts in this folder). The Bricolage Grotesque, Atkinson Hyperlegible Next,
Atkinson Hyperlegible Mono and Lexend files are static instances cut from the
upstream variable fonts (google/fonts) with fontTools; only the name table
was changed so each style has a predictable family name.

| File | Font | Source |
|---|---|---|
| BricolageGrotesque-*.ttf | Bricolage Grotesque (Ateliertriay) | github.com/google/fonts/tree/main/ofl/bricolagegrotesque |
| AtkinsonHyperlegibleNext-*.ttf | Atkinson Hyperlegible Next (Braille Institute) | github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext |
| AtkinsonHyperlegibleMono-*.ttf | Atkinson Hyperlegible Mono (Braille Institute) | github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblemono |
| Lexend-*.ttf | Lexend (Bonnie Shaver-Troup, Thomas Jockin) | github.com/google/fonts/tree/main/ofl/lexend |
| OpenDyslexic-*.otf | OpenDyslexic (Abbie Gonzalez) | github.com/antijingoist/opendyslexic |

"Vocal Ink Display" is Bricolage Grotesque at 96pt optical size, semi-condensed,
ExtraBold, given its own family name so the app can ask for it directly.
